# 稳定性默认参数调整（2026-10-22）

按用户要求，medium恢复为旧永川自动化项目的中档备用参数；low和high分别对应旧项目failure_prone和conservative的组合。三档是较弱、基准、较强的情景参数，不代表经过现场率定的土体参数或风险等级。

| 参数 | low | medium（默认） | high |
|---|---:|---:|---:|
| 土层厚度H/m | 2.0 | 1.5 | 1.0 |
| 饱和黏聚力c′/kPa | 3.0 | 6.0 | 12.0 |
| 饱和内摩擦角φ′/° | 14.0 | 16.0 | 18.0 |
| 初始饱和度 | 0.50 | 0.35 | 0.20 |
| 天然密度/(Mg·m⁻³) | 1.85 | 1.85 | 1.85 |
| 饱和密度/(Mg·m⁻³) | 2.10 | 2.10 | 2.10 |
| 径流等效密度/(Mg·m⁻³) | 1.50 | 1.50 | 1.50 |
| 摩阻流速换算系数a | 0.60 | 0.60 | 0.60 |

水密度维持1.0 Mg·m⁻³。将密度及a固定在相同水平，避免把强度情景与其他参数变化混在一起。基础配置、预设文件和计算核心缺省值已统一为medium。

## 生效范围

计划器合并顺序为基础配置→选定预设→人工覆盖，之后生成独立的任务配置。普通新建任务不再依赖medium名称推断数值，实际值明确写入config.yaml。

启用土地利用力学分区时，已匹配类别的H、c′、φ′和初始饱和度继续采用原地类参数表；预设中的这些值仅用于统一赋值或未匹配类别。不改变土地利用表，不按预设整体缩放各地类参数。因此，地类完全覆盖的案例中，三档可能得到相同的安全系数；不能把它们当作已完成的地类参数消融或强度敏感性实验。

reference_equation_9分支未把初始饱和度用于动态安全系数更新，修改该字段不代表引入入渗孔压耦合。

DEM读取及土地利用响应单元实现未改变。新永川运行保留相同输入包中的约12.49 m DEM与地类响应单元模式。历史任务配置与结果不追溯改写。

Sobol默认基础样本数随后按用户要求提高至2,048，与旧永川一致；五个参数对应14,336次模型评价，保持200次自助重采样、30,000个空间样本及原参数范围。旧任务明确记录的256样本配置仍保留原值，新任务使用2,048。

## 检查

- 三档与旧工程对应组合逐字段一致。
- 计划器、计算核心缺省值及medium一致。
- 人工覆盖值经过计划器和核心后保留。
- 已匹配地类保持原赋值，未匹配像元采用所选预设。
- 地类响应单元相关回归检查通过。
