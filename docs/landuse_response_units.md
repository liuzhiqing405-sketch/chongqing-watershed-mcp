# 分区内土地利用响应单元

自 2026-10-19 起，新建模型默认使用 `swmm.landuse_representation: response_units`。
`dominant` 仅供明确复算旧方案时选择；既有运行文件不会被自动迁移或覆盖。

## 计算规则

- 保留 GRASS 主分区、范围、原出口和分区插值降雨。
- 在原始 DEM 网格及已验证的计算掩膜内，统计每个主分区各地类的像元。
  分区像元归属采用中心点规则；地类栅格沿用现有土地利用栅格化规则，与同网格力学分区一致。
- 同一主分区内的同类斑块作为一个内部响应单元，保留空间索引，不给每块碎片另设出口。
- 内部单元面积按像元比例分配原主分区矢量面积，总面积守恒；保留原像元面积与分配面积两种统计供核对。
- 各地类分别使用已有不透水率、糙率和 Horton 参数。没有进行参数率定，也不将 Horton 曲线参数平均。
- 内部单元继承主分区坡度及降雨。宽度按面积比例缩放，使其有效坡长与主分区保持一致。
- 所有内部单元直接接入原主分区出口，不额外串联主分区产流计算，避免重复产流或重复汇流。
- 主分区统计表的不透水率按面积加权；混合分区的单值 Horton 参数及糙率留空，并标注仅为汇总行。
  实际计算参数以内部响应单元表和 INP 为准。
- 未识别地类保留独立面积和现有备用参数，不默默归入林地。没有有效原始像元的分区直接报错。

## 空间、时序及界面衔接

内部单元的 SWMM 产流按自身空间索引传递给稳定性网格，使用其单元面积将体积换成水深。
能够读取到的全零产流时序仍作为有效结果使用，不触发经验径流估算。

主分区过程由同时刻内部流量相加得到；峰值取相加后过程的最大值，不能累加各单元各自峰值。
界面中的分区数量、面积分布、峰值及过程图继续按主分区展示，同时说明内部响应单元数量。

SWMM 原生 GUI 的单一轮廓不能准确表达不连续的内部地类斑块，因此混合分区的内部单元不输出虚假的整分区显示多边形。
WebUI 使用原主分区矢量绘图；内部单元的完整空间分布由索引 GeoTIFF 保存并随成果导出。
SWMM 原生 GUI 因而不会显示每个内部单元的完整面状范围，计算面积仍由 INP 数值定义。

## 输出与质量检查

`swmm/model/` 新增：

| 文件 | 内容 |
|---|---|
| `auto_swmm_landuse_response_units.csv` | 单元、主分区、地类、面积、像元数、降雨、出口和实际参数 |
| `auto_swmm_landuse_response_index.tif` | 原始网格空间归属；1起索引，0为计算区外 |
| `auto_swmm_landuse_area_review.csv` | 原始地类面积与模型参数覆盖面积对比 |
| `auto_swmm_landuse_response_summary.json` | 算法口径、数量、面积及文件校验和 |

`swmm/results/auto_swmm_parent_runoff.csv` 输出主分区同时刻汇总后的峰值、峰现时间和报告步长积分体积。
报告步长积分是对输出时刻流量的数值积分，不等于引擎内部累积水量；正式水量账以原生 RPT 为准。

质量门槛检查 INP 与映射文件校验和、单元唯一性、降雨与出口连接、逐主分区总面积与不透水面积、
空间索引及各单元像元数。SWMM 成果包在新模式下必须携带内部映射文件，否则标为不完整。

## 验收与证据范围

- `tests/hydro/test_landuse_response.py` 覆盖混合地类、未知地类、面积及有效坡长守恒、
  错误连接与篡改、全零产流、逐像元体积守恒、主分区峰值合并，以及真实 SWMM 的同质分区拆分一致性。
- `scripts/accept_landuse_response.py` 在独立目录复制普子镇案例输入，执行新建模、SWMM、稳定性计算与导出，
  检查五类质量门槛及原案例文件未被改动，生成 `output/landuse_response_upgrade_20261019/acceptance_results.json`。这是历史输出路径；归档位置见 [项目整理记录](project_cleanup_20261105.md)，更早的输出可能位于归档内 `paper/` 的压缩包中。
- 本改动修复地类表达与结果传递，不意味着当地入渗参数已率定或事件预测精度已获观测验证。
