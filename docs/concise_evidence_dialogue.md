# 简洁对话与任务产物自主查阅

更新日期：2026-10-23。

## 用户可见行为

- 右侧不再展示“边界与水文检查”长面板。确认边界、编辑范围、准备输入、运行和刷新进度等操作继续可用。
- 准备降雨和模型输入时，默认只显示已完成的动作、必要的事件信息及下一步。文件数量、内部编号、英文阶段和整套局限不再反复堆入聊天。
- 图件的来源说明及下载入口折叠在“图件说明与下载”中；图件本身仍直接显示。
- 已有任务时，“评测区域稳定性”“这个结果如何”等问题优先解释当前结果。明确提出更换位置、降雨或重算时才进入相应操作。
- 用户追问参数、日志、模型、输入及检查时，模型自行选取当前任务的资料阅读，再组织回答。

## 模型可以读取什么

`list_hydro_readable_artifacts` 提供当前运行的完整只读目录，包括：

- 已登记的过程成果及最终成果；
- 运行项目目录中的原始输入、任务配置与中间文件；
- 该次运行的阶段日志、运行状态、任务记录及质量报告。

目录按文件给出稳定的成果编号，不把操作系统绝对路径交给模型。补充目录实时生成，不写入或改写下载成果登记表。

`inspect_hydro_artifact` 按目录编号读取。文本支持关键词和翻页；CSV/TSV 返回当前页及全部匹配行的数值列统计；矢量返回属性；栅格返回有效像元的统计；原生 SWMM 二进制返回已有模型解析摘要并说明范围。尚无解析器的文件只返回元数据，不能声称读过正文。

模型可在一次问答中继续请求阅读其他资料，当前上限为 5 次模型往返、8 次文件读取。这个上限控制单次响应成本，不缩小文件目录的访问范围。证据已经足够时可以直接回答。

只读调查接口没有运行、取消、确认、删除、导出或代码执行入口。读取范围由当前会话保存的运行编号确定；其他任务和目录外文件不可读取。文件中的指令作为资料处理。

## 稳定性结果如何解释

安全系数空间统计来自实际事件最小 Fs 栅格的全部有效像元，包含：

- Fs<1 面积、比例及其余区域比例；
- Fs 数值分段的面积与比例；
- 按计算域经纬度包络划分的九个方位，各自的低值面积及比例。

这里的“事件最小 Fs<1 比例”表示各像元在事件中曾达到过 Fs<1，不能替代“同一时刻最大失稳比例”。方位仅支持计算域层面的描述，不支持猜测村名、河名或具体成因。数值分段不是风险等级。

模型使用任务背景、实际统计和自主读到的资料形成自然回答，不再只对固定句子做词语替换。输出中的数值仍需通过证据核对；错误数值、明显不符的方位结论或无证据的安全保证会触发修正或回退。未完成或质量未通过的任务仍可回答已读文件的事实，但不能给出已验证的稳定性评价。

## 启用与验收范围

新 Python 后端和水文 MCP 必须重启才能生效；静态页面刷新后即可更新。先在旧 WebUI 终端按 Ctrl+C，再运行现有启动器：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_agent_latest.ps1
```

该启动器检查活动任务，重新加载已核实的项目服务，并在本机以掩码方式接收模型凭据。已有对话和计算成果保留。

自动验收使用可控模型响应检查理解后的路由、文件读取、修正和回退；使用实际任务检查真实 MCP 读取；使用真实栅格核对空间统计。这些检查不能替代接入有效 DeepSeek 凭据后的真实模型问答验收。报告原路径为 `output/conversation_ui_upgrade_20261023`，历史材料归档位置见 [项目整理记录](project_cleanup_20261105.md)，更早的输出可能位于归档内 `paper/` 的压缩包中。
