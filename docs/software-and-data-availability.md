# Software and data access

This repository contains the source code for Chongqing Watershed MCP.
Use the [repository home](../README.md) to browse the code and the
[quick start](getting-started.md) for installation and a runnable example.

The [data guide](../data/README.md) lists the included ERA5 precipitation sample
and Natural Earth reference rivers, links to ERA5 and CLCD, and explains how
to use a public 30 m elevation model. It also describes the access
conditions for the original third-party inputs.
