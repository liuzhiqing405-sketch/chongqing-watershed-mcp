# Configuration

- `agent.default.yaml` and `agent.deepseek.yaml` configure the agent, model connection and local services.
- `spatial.default.yaml` defines dataset paths and spatial processing settings.
- `hydro.default.yaml` sets hydrology and stability calculation defaults.
- `stability_presets.yaml` defines parameter presets.
- `quality_gates.yaml` defines checks for model inputs and outputs.
